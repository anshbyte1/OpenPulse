# Contributing to OpenPulse

Thanks for considering a contribution!

## Getting started
1. Fork the repository and create a branch for your change.
2. Install dependencies with pip install -r requirements-dev.txt.
3. Make a focused change and add or update tests.
4. Run pytest before opening a pull request.
5. Explain the problem, approach, and limitations in your PR.

## Guidelines
- Keep the app simple and code readable.
- Never commit access tokens, secrets, or personal data.
- Keep API calls bounded and respect GitHub rate limits.
- Do not present activity metrics as definitive quality or security scores.
- Include tests for new analysis behavior.

For larger changes, open an issue first so we can discuss the design.
